# Security Policy

## Supported versions

Open Incident is in **alpha**. Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

- Preferred: [GitHub private vulnerability reporting](../../security/advisories/new)
- Alternatively: security@open-incident.com

You can expect an acknowledgement within 72 hours. Please include reproduction
steps and the affected version or commit. Coordinated disclosure is
appreciated — we will credit reporters in the release notes unless you prefer
otherwise.
